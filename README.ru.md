# TCL Display — телевизор и дисплей Windows через HACS

Интеграция создаёт полноценный медиаплеер TCL и сама синхронизирует дисплей Windows с выбранным входом телевизора. **Вся настройка в интерфейсе HA: без YAML, помощников и отдельных автоматизаций.**

## Что понадобится

- Home Assistant 2026.10 или новее, HACS.
- Уже настроенный TCL через **Android Debug Bridge**, например `media_player.tcl`.
- Готовые отдельные скрипты переключения входов. HDMI 3 используется для этого ПК.
- Windows 10/11 x64 с подключённым телевизором. Пользователь должен войти в Windows.

## Установка

1. HACS → меню → **Пользовательские репозитории**.
2. Добавь `https://github.com/BrainDeLook/tcl-display`, категория **Интеграция**.
3. Установи **TCL Display** и перезапусти HA.
4. Из [Releases](https://github.com/BrainDeLook/tcl-display/releases) скачай Windows-приложение, распакуй в постоянную папку и запусти `TCL-Display.exe`.
5. Выбери TCL в списке дисплеев, проверь домашний IPv4 компьютера, введи IPv4 HA. Сохрани настройки, нажми **«Разрешить доступ HA…»** и подтверди запрос Windows, затем **«Запустить обработчик»**.
6. На ТВ выбери HDMI 3 и вручную проверь кнопки подключения и отключения TCL.
7. В приложении открой **«Настройка HA» → «Копировать строку»**.
8. В HA: **Настройки → Устройства и службы → Добавить интеграцию → TCL Display**.
9. Вставь строку подключения. Затем выбери сам телевизор TCL, необязательную сущность громкости `number` и готовые скрипты для HDMI / Google TV из списков.

Это установка через пользовательский репозиторий HACS; в стандартный каталог HACS интеграция пока не включена.

## Что появится

- **Медиаплеер**: питание самого TCL, реальные источники, громкость JBL через выбранную сущность `number` с её настоящими min/max.
- **Дисплей ПК на TCL**: ручное подключение / отключение в Windows.
- **Автоматическая синхронизация**: можно выключить, если нужен ручной режим.
- **Связь с Windows**: диагностический датчик доступности ПК.

Выбор HDMI 3 в новом медиаплеере запускает твой скрипт входа, ждёт обнаружения HDMI и включает дисплей Windows. Переключения пультом определяются примерно за 15 секунд. Выбор другого подтверждённого источника или выключение телевизора отключает дисплей ПК. Неизвестный вход, переходное состояние и потеря связи не считаются командой отключения.

Во время переключения на другой источник действует короткое ожидание подтверждения: старый ответ ТВ не должен отменять только что отправленную команду. Статус источника обновляется по чтению ТВ, а не по факту нажатия кнопки.

В ручном режиме сначала выключи **«Автоматическая синхронизация»**, иначе очередной опрос вернёт дисплей к состоянию согласно источнику ТВ.

## Если уже использовал старые YAML

После проверки новой интеграции **отключи старые автоматизации определения источника и управления дисплеем Windows**. Иначе два механизма будут отправлять команды одновременно.

В мастере выбирай исходные скрипты `script.tcl_hdmi_1`, `script.tcl_hdmi_2`, `script.google_tv_domoj`, `script.tcl_hdmi_3`, а не старый общий `tcl_hdmi_selector`. Старый Universal media player и `input_select` можно убрать, если они больше нигде не используются. Интеграцию Android Debug Bridge и исходные скрипты оставь.

## Изменение настроек

В интеграции **«Настроить»** — телевизор, громкость, скрипты и названия входов. **«Перенастроить»** — адрес ПК / новая строка подключения. При неправильном ключе HA предложит повторную авторизацию.

Windows-приложение поддерживает независимые настройки иконки трея и действия крестика. Без значка скрытое окно открывается повторным запуском EXE, второй процесс не создаётся. **«Завершить»** полностью останавливает приложение. При обновлении сохрани свой `agent.ini` рядом с новым EXE.

## Ограничения

- ПК должен быть включён; приложение не будит его из сна и работает в локальной пользовательской сессии.
- Видеодрайвер должен обнаруживать телевизор. Поэтому при выборе HDMI 3 сначала переключается сам ТВ, затем включается дисплей ПК.
- При подключении Windows может выбрать совместимый видеорежим. Полный профиль HDR, частоты и расположения экранов эта версия не сохраняет; TCL добавляется справа.
- На разных прошивках TCL формат ADB-ответов может отличаться. Определение HDMI нужно проверить на конкретном ТВ.
- Закрепи IP компьютера и HA в DHCP роутера. Разрешение брандмауэра действует только для указанного IPv4 HA и частного профиля сети Windows.
- Строка подключения содержит секрет. Не публикуй её и не открывай HTTP-порт приложения в интернет.

## Проверки

GitHub Actions проверяет код, мастер настройки и сущности в настоящем Home Assistant, разбор ответов ТВ и HTTP-протокол, а также hassfest / HACS. Физическое подключение и отключение дисплея на ПК и всю связку с твоим HA нужно проверить вручную.
