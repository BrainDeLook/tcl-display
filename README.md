## Быстрый старт

1. **ПК:** скачай установщик, нажми «Установить» и открой TCL Display из меню «Пуск». Программа хранится в `%LocalAppData%\Programs\TCL Display`, настройки — в `%LocalAppData%\TCL Display`. Старую portable-версию сначала заверши; её `agent.ini` можно перенести через мастер установки.
2. **Приложение:** выбери дисплей, сохрани настройки, разреши доступ HA и запусти обработчик. Во вкладке «Настройка HA» скопируй строку подключения.
3. **HA:** добавь этот репозиторий в обычный HACS как **Интеграцию**, установи TCL Display и перезапусти HA. Для уже установленной версии обновись до **0.6.0**. Если кнопка HACS не открывается, добавь вручную `https://github.com/BrainDeLook/tcl-display`.
4. **Подключение:** Настройки → Устройства и службы → Добавить интеграцию → TCL Display. Вставь строку из приложения. При обновлении повторное подключение не нужно.

## Сохранение разрешения и частоты

После обновления до Windows 1.8 один раз включи телевизор, выставь в Windows нужный режим (например, **2560×1440, 120 Гц**) и нажми **«Запомнить текущий режим ТВ»** в приложении. При следующих подключениях будут восстановлены сохранённые параметры. Перед отключением через приложение/HA текущий режим также сохраняется автоматически. При невозможности применить сохранённый режим будет показана ошибка вместо тихого сброса на 4К 60 Гц.

Включение ждёт обнаружения телевизора до 3,5 секунд, подтверждение драйвера — до 3 секунд. Это не включает питание телевизора: в автоматизации сначала включи ТВ/переключи на вход ПК, затем включай «Дисплей Windows». Если ТВ запускается дольше, выдержи задержку до готовности HDMI. В ошибках HA теперь видны `win32` и `stage`; локальный журнал команд находится в `%LocalAppData%\TCL Display\agent.log`.

## Раскладка значков рабочего стола

В приложении 1.8 на вкладке **«Поведение»** есть галочка **«Сохранять и возвращать расположение значков»** (включена по умолчанию). Непосредственно **до подключения ТВ в Windows** сохраняется актуальное расположение значков файлов, папок и ярлыков на всех текущих мониторах. После отключения ТВ приложение ждёт возврата экранов и восстанавливает координаты. При каждом новом цикле сохраняется свежая раскладка; повторная команда включения в том же цикле не затирает снимок.

Это работает и без режима основного ТВ. Снимок хранится в `%LocalAppData%\TCL Display\desktop-icons.bin` и сохраняется после перезапуска приложения. Для восстановления должны вернуться прежние мониторы, разрешения, позиции, масштаб и размер значков. Автоматическое упорядочивание значков в Windows должно быть выключено. Если сохранить снимок не удалось, подключение не применяется. Если после отключения вернуть значки не удалось, дисплей остаётся отключённым, а в журнале HA появляется предупреждение. Повторная команда отключения повторит попытку восстановления. Новые/переименованные элементы не удаляются и не переименовываются.

При переходе со старой версии сначала самостоятельно восстанови удобную раскладку: прежнее приложение её не сохраняло. Защита работает для следующих подключений/отключений через приложение или HA; ручное выдёргивание HDMI и изменения экранов вне приложения не запускают восстановление.

## Два переключателя

- **Дисплей Windows** — подключает телевизор к рабочему столу Windows или программно отключает его. Это действие соответствует настройке «Отключить этот дисплей», а не питанию ТВ.
- **Делать ТВ основным** — отдельная настройка в разделе конфигурации устройства. Когда режим включён, следующая команда подключения делает ТВ основным, а отключение возвращает прежний монитор. Память о нём сохраняется после перезапуска. По умолчанию режим выключен.

Привяжи переключатель дисплея к своим существующим скриптам HDMI или медиаплееру. Интеграция сама не переключает входы телевизора.

Приложение нативное, без .NET, Python и HASS.Agent. Есть автозапуск, скрытие в фон и независимая настройка значка в трее. Обновление — повторным запуском установщика, удаление — через список приложений Windows. Настройки сохраняются.

Подключение предназначено для доверенной домашней сети. Не открывай порт в интернет и не публикуй строку подключения: она содержит ключ.

## Сборка

Исходники Windows — `windows/`, интеграция — `custom_components/tcl_display/`, фирменные изображения — `assets/` и `brand/`. Сборка приложения: `windows/build.ps1` (Zig 0.13); установщика: `windows/build-installer.ps1` (Inno Setup 6). CI проверяет протокол, Home Assistant, HACS, нативную логику, установку, обновление и удаление.
