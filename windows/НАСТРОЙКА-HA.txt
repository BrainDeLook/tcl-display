# TCL Display

Лёгкое приложение Windows и интеграция Home Assistant с **управлением дисплеем и отдельным режимом основного экрана**.

Включение переключателя подключает выбранный экран к рабочему столу Windows. Выключение отключает его, как «Отключить этот дисплей» в настройках Windows. Это не управление питанием телевизора. Состояние читается с ПК каждые 15 секунд, после команды обновляется сразу. Если ПК или экран недоступен, переключатель становится недоступным.

Приложение написано на C/Win32: один процесс без Python, .NET и HASS.Agent. Есть графическая настройка, автозапуск, показ/скрытие иконки в трее и независимый выбор действия крестика: выход или продолжение работы в фоне. Кнопка «Завершить» всегда закрывает приложение. Для возвращения скрытого окна запусти EXE ещё раз.

## Установка приложения

1. [Скачай установщик TCL-Display-Setup.exe](https://github.com/BrainDeLook/tcl-display/releases/latest/download/TCL-Display-Setup.exe), запусти и нажми «Установить». Программа установится для текущего пользователя в `%LocalAppData%\Programs\TCL Display`, без обязательных прав администратора.
2. Если раньше использовалась portable-версия, сначала нажми в ней **«Завершить»**. Установщик предложит перенос её `agent.ini`: найди его в старой папке приложения. При наличии старого автозапуска файл определяется автоматически. Действующие настройки установленной версии никогда не перезаписываются.
3. Открой **TCL Display** из меню «Пуск». Выбери телевизор, проверь IPv4 ПК, укажи IPv4 HA для правила брандмауэра. Нажми «Сохранить настройки», затем «Разрешить доступ HA…» и подтверди системный запрос Windows. Правило рассчитано на частный сетевой профиль.
4. Запусти обработчик. Настрой автозапуск и поведение окна по желанию.
5. Во вкладке «Настройка HA» скопируй строку подключения. Она содержит секретный ключ — не публикуй её.

Настройки и строка подключения хранятся отдельно от программы: `%LocalAppData%\TCL Display\agent.ini` и `connection.txt`. Кнопка «Открыть папку» показывает эту папку. Для обновления заверши приложение и снова запусти установщик. Удаление доступно через **Параметры Windows → Приложения**; настройки остаются для повторной установки. Установщик не включает автозапуск сам; существующий автозапуск переносится на установленный EXE.

## Что сделать в Home Assistant

1. В **обычном HACS** открой пользовательские репозитории, добавь `https://github.com/BrainDeLook/tcl-display`, тип **Интеграция**. Установи TCL Display и перезапусти HA. Если уже установлено — обнови до 0.4.0 и перезапусти HA.
2. Открой **Настройки → Устройства и службы → Добавить интеграцию → TCL Display**.
3. Вставь строку из приложения Windows, при желании задай имя. Больше сущностей или скриптов выбирать не нужно.
4. На устройстве появятся **Дисплей Windows** и переключатель настройки **Делать ТВ основным**. Второй находится в разделе конфигурации устройства. По умолчанию режим выключен. Включи его, если ТВ должен становиться основным при подключении. Фактические entity_id видны в настройках сущностей.
5. В своих существующих скриптах/автоматизациях вызывай `switch.turn_on` для этого переключателя при выборе HDMI 3, а `switch.turn_off` при уходе с него. Привязку к существующему медиаплееру ты настраиваешь самостоятельно.

Интеграция не создаёт медиаплеер, не меняет вход телевизора и не отправляет команды при запуске или обычном опросе. ADB и скрипты источников ей не нужны. Старые настройки синхронизации из 0.1.0 удаляются при миграции; прежний переключатель дисплея сохраняется. Старые созданные этой интеграцией медиаплеер, автоматическая синхронизация и датчик соединения удаляются; существующий Universal Player не затрагивается.

При смене адреса или ключа используй **Перенастроить** в меню интеграции и вставь новую строку. Закрепи IP ПК в DHCP. Доступ предназначен для доверенной локальной сети: HTTP с ключом, без шифрования. Не открывай порт в интернет.

Отключение последнего активного экрана запрещено. Включение добавляет экран справа от текущих; сохранение полного профиля HDR/частоты/раскладки не реализовано. Работа с конкретным драйвером проверяется на твоём ПК.

## Режим основного экрана

«Делать ТВ основным» сохраняет настройку в приложении; переключение самого режима не меняет рабочий стол. При следующей команде включения дисплея ТВ станет основным, а при отключении прежний основной монитор вернётся. Можно также включить уже подключённый ТВ повторной командой `switch.turn_on` для дисплея.

Прежний монитор запоминается в `agent.ini` до применения изменений и сохраняется после перезапуска приложения/Windows. Повторное включение не перезаписывает его телевизором. Если прежний монитор отключён от ПК, основным станет один из оставшихся активных экранов. Если выключить режим, пока ТВ основной, при отключении ТВ прежний монитор всё равно восстановится. Автоматический возврат происходит по команде отключения через приложение/HA, а не при ручном отключении кабеля.

Этот режим также доступен в приложении на вкладке «Поведение»; настройка сохраняется сразу. На старом приложении переключатель режима в HA недоступен: обнови Windows-приложение до 1.6. Подключение к HA и существующий переключатель дисплея сохраняются.

## Иконки

Один значок используется в EXE, окне приложения, трее, ярлыках и установщике. Интеграция содержит локальный `brand/` с PNG 256/512 px и логотипами для светлой и тёмной темы. Изображения устанавливаются вместе с интеграцией; отдельный репозиторий с иконками не нужен. После обновления HA перезапусти его и обнови страницу браузера, если виден старый значок.

## Разработка

Интеграция: `custom_components/tcl_display`. Windows: `windows/src`, сборка `windows/build.ps1` с Zig 0.13. Нативные проверки: `windows/test.ps1 -Zig <путь к zig.exe>` (искусственная конфигурация, реальные экраны не меняются). CI проверяет протокол, реальные API Home Assistant, hassfest и HACS.
