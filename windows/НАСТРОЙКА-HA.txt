TCL Display 1.3 — настройка через HACS

1. Установи интеграцию из https://github.com/BrainDeLook/tcl-display через пользовательский репозиторий HACS (категория «Интеграция»). Перезапусти HA.
2. В приложении Windows выбери TCL, IPv4 ПК и IPv4 Home Assistant. Сохрани настройки.
3. Разреши доступ HA соответствующей кнопкой, подтверди UAC и запусти обработчик. Сеть Windows должна иметь частный профиль.
4. Выбери HDMI 3 на ТВ и вручную проверь кнопки подключения / отключения дисплея.
5. На вкладке «Настройка HA» нажми «Копировать строку».
6. В HA: Настройки → Устройства и службы → Добавить интеграцию → TCL Display.
7. Вставь строку, выбери физический TCL из Android Debug Bridge, сущность громкости number и отдельные скрипты входов. Остальное делает интеграция: создаёт медиаплеер, читает реальный источник и синхронизирует дисплей ПК.
8. Отключи старые YAML-автоматизации синхронизации, если добавлял их ранее, чтобы они не конфликтовали с интеграцией. Выбирай исходные скрипты входов, а не общий старый selector.

Ключ, порт и адрес переносятся одной строкой. Эта строка секретная: передавай её только своему HA.
Для изменения телевизора, скриптов и названий входов используй «Настроить» у интеграции. Для смены адреса ПК — «Перенастроить».

ПОВЕДЕНИЕ ПРИЛОЖЕНИЯ
На вкладке «Поведение» независимо выбери значок трея и действие крестика. Нажми «Применить поведение». Когда окно скрыто без значка, повторный запуск EXE возвращает работающий экземпляр. «Завершить» всегда полностью выключает приложение.
Автозапуск — через галочку на первой вкладке и сохранение настроек. При переносе в другую папку обнови автозапуск. При обновлении сохраняй agent.ini.

ПК должен быть включён, пользователь — войти в Windows. Приложение не будит спящий ПК. Телевизор должен обнаруживаться видеокартой. Источники, переключённые пультом, обновляются примерно за 15 секунд.
При подключении дисплея Windows выбирает доступный режим. Отдельного сохранения полного профиля HDR/частоты/расположения в этой версии нет.
